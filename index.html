What is TokenForge?

A Python CLI wizard that asks 5 questions and deploys your token contract directly to Ethereum, Polygon, Arbitrum, Base — or any EVM chain.

🔓

Open Source

MIT licensed. Read every line of the Solidity contracts and Python code. No black boxes.

⛓️

Multi-Chain

Same script, same contracts. Deploy to 6 pre-configured networks or custom RPC.

⚡

Terminal-First

No web forms. No SaaS subscriptions. A clean interactive wizard that takes under 60 seconds.

🛡️

You Own It

Your private key, your contract, your supply. No platform can freeze or revoke your tokens.

Auditable

Minimal Solidity based on OpenZeppelin patterns. Bytecode matches source — verify on Etherscan in one click.

💰

Free Forever

Platforms charge $500–$5,000 per deployment. TokenForge costs nothing. Just pay blockchain gas.

How it works

From source code to on-chain token in four steps.

Write Parameters

Name your token, choose a symbol, set decimals and initial supply.

Compile Solidity

TokenForge compiles the ERC-20 or ERC-721 source locally using solc v0.8.20.

Sign & Broadcast

Your private key signs the deployment transaction. Gas is estimated automatically.

Token Is Live

The contract address appears. Verify on Etherscan. Start transferring.

Supported Standards

From simple tokens to permissioned securities.

🪙

ERC-20  LIVE

Fungible tokens. Currencies, shares, loyalty points, commodities. Full supply minted to deployer on creation.

🖼️

ERC-721  LIVE

Non-fungible tokens. Real estate, invoices, art, certificates. Mint-on-demand with per-token metadata URI.

🏦

ERC-3643  NEXT

Permissioned security tokens. On-chain identity whitelisting, transfer restrictions, forced transfers for compliance.

🎮

ERC-1155  PLANNED

Multi-token standard. One contract for both fungible and non-fungible tokens. Ideal for gaming and bundled assets.

📈

ERC-4626  PLANNED

Tokenized vaults. Yield-bearing assets like treasury bills, staking positions, and interest-bearing accounts.

🔌

Custom  PLANNED

Plugin system for custom token logic. Extend TokenForge with your own Solidity modules.
