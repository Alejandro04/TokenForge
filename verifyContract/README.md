# Verify Contract

Publish your deployed contract's source code on Etherscan so anyone can read
and interact with it directly from the block explorer.

## Why Verify?

Without verification, Etherscan shows raw bytecode only:

```
0x608060405234801561000f...
```

After verification, it shows the human-readable Solidity:

```solidity
contract TokenForgeERC20 {
    string public name;
    string public symbol;
    // ...
}
```

Verification also enables the **Read Contract** / **Write Contract** tabs,
letting anyone call `balanceOf`, `transfer`, `mint`, etc. without writing code.

## Quick Start

```bash
python verifyContract/verify_contract.py
```

### What the script does

1. Asks for your contract's standard, name, symbol, and constructor parameters.
2. Computes the ABI-encoded constructor arguments.
3. Saves the Solidity source to a `.sol` file in the current directory.
4. Opens the Etherscan verification page in your browser.
5. Prints all the values you need to paste into the form.

### What you paste into Etherscan

| Field | Value |
|-------|-------|
| Compiler Type | Solidity (Single File) |
| Compiler Version | `v0.8.20+commit.a1b79de6` |
| License | MIT |
| Source Code | Contents of the generated `.sol` file |
| Constructor Arguments | The long hex string printed by the script |
| Optimization | No |

Click **Verify and Publish**. Confirmation takes ~10 seconds.

## Troubleshooting

**"Unable to find matching Contract Bytecode"**

- Make sure the compiler version matches exactly: `v0.8.20+commit.a1b79de6`
- Constructor arguments must match exactly what was used at deployment time
- The source code must be identical to what `tokenforge.py` compiled
- Use the `.sol` file generated by this script (do not modify it manually)

**No API key needed**

The script uses Etherscan's web verification form, which is free and requires
no registration. You only need an API key for programmatic verification.
